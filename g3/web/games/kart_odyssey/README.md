# Kart Odyssey

Not started. Cosmic grand-prix racing for up to 4 puffers: drift through nebula tracks, grab boosts, take the cup.

To build it: add game.js here (and a DOM-free simulation/rules file if it has game logic), register it with
G3.registerGame('kart_odyssey', { mount }), and add its <script> tags to lobby.html. See [../README.md](../README.md).
