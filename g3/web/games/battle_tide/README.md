# Battle Tide

Not started. **Naval tactics**: command a fleet of battleships, destroyers and submarines across the tide, trade broadsides and sink the enemy
fleet. 1-4 players for now.

**Style reference:** the cover art, [assets/covers/battle_tide.png](../../assets/covers/battle_tide.png): comic-ink warships in a stormy orange
sunset, heavy smoke and shell fire, teal waves, a radar-circle overlay with orange crosshair brackets, a distressed stencil title.

To build it: add game.js here (and a DOM-free simulation/rules file if it has game logic), register it with
G3.registerGame('battle_tide', { mount }), and add its <script> tags to lobby.html. See [../README.md](../README.md).
