# Rising Rush

Not started. **Boss rush**: a band of stick-figure ninjas (red, gold and cyan fighters in the cover art) against towering bosses; team up,
time your strikes and bring each boss down. 1-8 players for now (the cover shows three heroes, so the real limit may be lower).

**Style reference:** the cover art, [assets/covers/rising_rush.png](../../assets/covers/rising_rush.png): bold ink-brush title, black silhouette
fighters with glowing red / gold / cyan trails, a huge red sun and misty mountains behind, a dark purple horned boss.

To build it: add game.js here (and a DOM-free simulation/rules file if it has game logic), register it with
G3.registerGame('rising_rush', { mount }), and add its <script> tags to lobby.html. See [../README.md](../README.md).
