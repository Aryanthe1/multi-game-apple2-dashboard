# Who's Away From Home

Not started. A co-op mystery escape room in an empty mansion for 1-4 players: search rooms, combine clues, crack the lock together.

To build it: add game.js here (and a DOM-free simulation/rules file if it has game logic), register it with
G3.registerGame('whos_away', { mount }), and add its <script> tags to lobby.html. See [../README.md](../README.md).
