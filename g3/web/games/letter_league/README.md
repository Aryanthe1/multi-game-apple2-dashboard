# Letter League

Not started. A co-op word puzzle on one shared board; longer words and combos score for the whole team. 1-8 players.

To build it: add game.js here (and a DOM-free simulation/rules file if it has game logic), register it with
G3.registerGame('letter_league', { mount }), and add its <script> tags to lobby.html. See [../README.md](../README.md).
