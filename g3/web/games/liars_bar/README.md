# Liar's Bar

Not started. Deck bluffing and dice for 2-4 players: play cards face-down, call a bluff, outlast the table.

To build it: add game.js here (and a DOM-free simulation/rules file if it has game logic), register it with
G3.registerGame('liars_bar', { mount }), and add its <script> tags to lobby.html. See [../README.md](../README.md).
