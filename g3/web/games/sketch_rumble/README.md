# Sketch Rumble

Not started. 1 player draws the secret prompt, everyone else guesses the word in real time; the fastest correct guesses win the most points. 1-16 players.

To build it: add game.js here (and a DOM-free simulation/rules file if it has game logic), register it with
G3.registerGame('sketch_rumble', { mount }), and add its <script> tags to lobby.html. See [../README.md](../README.md).
